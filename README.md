## Selected projects

### [Financial Document Intelligence](https://github.com/estaciolima/balanco_llm)

An auditable pipeline for extracting structured financial information from PDF documents using large language models, deterministic accounting validation, and asynchronous processing.

**Stack:** Python, Django, PostgreSQL, Celery, Redis, OpenAI API, Docker.

### [Bayesian Credit Risk Modeling](https://github.com/estaciolima/rede_bayesiana_inadimplencia)

An exploratory comparative study of logistic regression, Bayesian networks, Naive Bayes, and Tree-Augmented Naive Bayes for credit default prediction.

**Stack:** R, bnlearn, tidymodels, pROC.

### Sequential Anomaly Detection in Industrial Time Series

Master's research on Multiregression Dynamic Models (MDMs) and Bayesian sequential monitoring applied to multivariate time series from Petrobras' [3W Dataset](https://github.com/petrobras/3W).

The research investigates local and global change-point detection using predictive Bayes factors, CUSUM, and bilateral Bayesian monitoring, with reproducible experiments.

**Stack:** R, renv.

*The research implementation is currently private.*
